# Prompt 构建指南

```python
def _build_prompt(self, product_feature: str, tone: str, target_audience: str) -> str:
    """构建提示语"""
    
    tone_map = {
        "professional": "专业",
        "casual": "随意",
        "enthusiastic": "热情",
        "luxurious": "奢华"
    }

    audience_map = {
        "general": "大众",
        "young": "年轻人",
        "business": "商务人士",
        "premium": "高端用户"
        }

    prompt = f"""你是一位资深的营销文案专家。请根据以下产品卖点，生成3条不同类型的营销文案。
        【产品卖点】
        {product_feature}

        【写作要求】
        - 语气风格：{tone_map.get(tone, "专业")}
        - 目标受众：{audience_map.get(target_audience, "大众")}
        - 每条文案长度控制在100字以内
        - 突出产品核心价值
        - 包含明确的行动号召

        【三条文案类型】
        1. 痛点切入型：强调用户的痛点，展示产品如何解决问题。
        2. 情感共鸣型：通过情感共鸣引起用户兴趣，展示产品带来的美好体验。
        3. 价值展示型：直接突出产品的核心优势和独特卖点，吸引注重实用性的用户。

        请根据以上要求生成3条营销文案，每条文案前面标注类型,用[文案1]、[文案2]、[文案3]进行区分，每条文案之间空一行。"""
    return prompt
```
## 一、参数清单

### 主要参数
- **Role（角色）**：你是一个 xxx
- **Task（任务）**：核心指令
- **Context（背景）**：必要上下文
- **Target Audience（目标受众）**：写给谁看
- **Tone（语气）**：风格基调

### 次要参数
- **Format（输出格式）**：JSON、列表、表格等
- **Length（输出长度）**：字数、句数、段数
- **Constraint（约束）**：禁止项、强制项
- **Example（示例）**：few-shot 样例

---

## 二、黄金公式（4 要素）
角色 + 任务 + 细节约束 + 输出格式
### 1. 角色
让模型代入身份，**非必须但强力推荐**。

| ❌ 错误 | ✅ 正确 |
|--------|--------|
| 解释量子计算 | 你是一位物理教授，用高中生能听懂的方式解释量子计算 |

### 2. 任务
使用**强动词**明确动作。

| ❌ 模糊 | ✅ 清晰 |
|--------|--------|
| 处理、帮忙、看看 | 总结、翻译、分类、生成、提取、改写、对比、评分 |

### 3. 细节约束
控制输出的关键差异点：

- **受众**：面向非技术人员
- **语气**：语气严肃，不要用表情符号
- **长度**：控制在 100 字以内
- **禁止项**：不要提到价格

### 4. 输出格式
明确结构，避免模型自由发挥：

- “用三句话回答”
- “输出 JSON：`{"原因": "...", "建议": "..."}`”
- “先给结论，再用列表列出 3 个理由”

---

## 三、进阶技巧

| 技巧 | 说明 |
|------|------|
| **负面约束** | 明确告诉模型“不要做 X”，比只说“要做 Y”更有效 |
| **给示例** | 输出格式复杂时，1-2 个例子优于 10 条说明 |
| **展示思考过程** | 要求模型“一步一步思考”，尤其适用于逻辑推理 |
| **分隔符** | 用 `【】` 或 `---` 明确各部分的边界 |

---

## 四、自检清单（5 问）

发送前问自己：

- [ ] 模型能一眼看懂要做什么吗？
- [ ] 有没有需要模型猜测的地方？
- [ ] 输出格式有没有明确？
- [ ] 有没有反向约束（禁止项）？
- [ ] 如果去掉 50% 的文字，意思还完整吗？

## 五、模板（可直接复制）

```markdown
***Role***  
你是一名 [职位/身份]

***Task***  
[动词] + [对象]

***Context***  
[必要的背景信息，不超过 3 句话]

***Constraints***
- 面向 [受众]
- 语气 [形容词]
- 长度 [数字] [字/句/段]
- 不要 [禁止项1、2]

***Output Format***  
[具体结构，如：标题 + 3个要点 + 结尾一句话]
```

## 六、核心总结
差的 prompt 让模型猜你的需求；好的 prompt 让模型不用猜。
